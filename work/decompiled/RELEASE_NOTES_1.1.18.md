# MISE 1.1.18

リリース日：2026年9月2日

## 選択ハンドルの表示改善

- 拡大縮小ハンドルのキャンバス上の寸法を、画面ズーム倍率の逆数で補正する方式へ変更しました。
- 25～400％のどのズーム倍率でも、ハンドルは画面上で約9pxの操作サイズを維持します。
- 高倍率ズーム時に拡大縮小ハンドルが文字や画像を覆い、中身を確認できなくなる問題を修正しました。
- 回転ハンドルは画面上約12pxを維持し、オブジェクトからの表示距離も一定にしました。
- 選択枠の線幅もズーム補正し、ズーム倍率によって極端に太くならないようにしました。

## 継承する修正

- Ctrl＋Z／Ctrl＋Yの全体履歴化、Ctrl＋Shift＋Z対応、操作ページ・選択対象の復元を維持します。
- 文字を縦横比を維持したまま3ptまで縮小できる仕様を維持します。
