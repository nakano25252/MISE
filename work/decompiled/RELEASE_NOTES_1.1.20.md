# MISE 1.1.20

リリース日：2026-09-02

## 修正

- ロック中の要素を、削除・移動・整列・複製・スタイル変更・レイヤー変更から一貫して保護
- ロック要素を含む複数選択では、編集可能な要素だけを操作
- 面付け元ページを指定DPIで描画し、文字・細線・QRの画質低下を修正
- タイト文字の縦横別拡大を廃止し、字形の比率を維持
- 画像の実効DPIを幅と高さの低い方から判定
- 埋め込みフォントをレイアウト検証で正しく認識
- 複数選択時のアクティブ要素を固定し、プロパティ対象が不定になる問題を修正
- PDFメタデータのバージョンを実行中のアプリ版へ連動

## 保存・読み込み

- プロジェクト保存形式を2へ更新
- 古いデータの座標・サイズ・回転・透明度・文字サイズ等を読み込み時に安全な範囲へ補正
- 未対応の将来形式を明示的に拒否
- PDF／AI原本が見つからない場合、高精細な再描画ができないことを検証画面で警告
- PDF／AI編集読込の近似変換に関する制約を表示し、画像の編集変換を既定でオフへ変更

## 互換性

- 1.1.19以前のプロジェクトを読み込み可能
- Windows 10／11 64bit向け自己完結型単一EXE
