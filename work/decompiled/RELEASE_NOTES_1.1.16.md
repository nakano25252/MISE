# MISE 1.1.16

## PDF／Illustrator AIの詳細読み込み

- 読み込み画面を「編集優先」「見た目優先」「詳細設定」の3系統へ変更
- 詳細設定で、文字と画像を別々に編集可能オブジェクトへ変換可能
- 「文字は元の見た目のまま、画像だけ編集可能」な読み込みに対応
- 「文字だけ編集可能、画像は元の見た目のまま」の読み込みに対応
- チェックを外した種類は固定背景に残し、元デザインの外観を維持
- PCに存在しないフォントを使用した文字だけ、固定背景として保持する設定を追加
- 固定背景の品質を長辺2600px／5200pxから選択可能
- 編集対象にした要素だけ元位置をマスクし、個別の移動・拡大縮小・回転・削除に対応

## 継承内容

- 文字オブジェクトのカーソル追従拡大縮小
- 新規文字の初期フォントサイズ34pt
- PDF互換データを含むIllustrator AIの読み込み
