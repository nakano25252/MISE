# MISE 1.1.21 — 状態復元の修正

- Undo／Redo専用の復元経路を分離し、ファイル移行・数値補正で履歴の座標・角度・寸法が変わる問題を修正。
- 履歴にアクティブ要素IDを保存し、複数選択の復元時にプロパティ対象も復元。
- フォント埋め込みの履歴取得を変更前へ移動。ロック文字への自動適用を防止。
- 4ページの文書、PDFページ番号、3pt文字、画像原本、ロック状態、将来形式拒否の回帰テストを追加。
- 右クリック・ツールバー・プロパティのロック変更を共通化。選択順によって一括ロック結果がばらつく問題を修正し、変更なしでは履歴を追加しない。
- ロック中の線への右クリック設定変更を防止。線端・矢印サイズ変更時にプロパティ表示を同期。
- ドラッグ縮小時に開始フォントサイズの5％で停止する制限を除去し、数値入力と共通の3〜300pt制限を使用。
- タイト文字の最低12px枠と固定余白を廃止。小さな要素の描画・出力枠への4px補正と文字ドラッグ枠の1px補正も除去し、実寸を維持。
- Windows上で3ptの英字・句読点・日本語・複数行を描画し、外接範囲とピクセル端を検査する回帰テストを追加。

この版は実用化の第一段階です。複数選択変形、無変更Undo、PDF編集再構成、実機印刷の検証は未完了です。
